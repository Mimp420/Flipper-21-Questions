# Mini Arcade for Flipper Zero

Five games in one Flipper Zero app:

1. Reaction Test
2. Pocket Snake
3. Dice Duel
4. Memory Lights
5. Treasure Hunt

Use `UP` and `DOWN` in the main menu and press `OK` to play. Press `BACK` inside a game to return to the arcade menu.

The GitHub workflow builds `mini_arcade.fap` automatically. Copy it to `SD Card/apps/Games/` using qFlipper.
